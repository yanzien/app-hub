## ✨ 功能模块

### 1. 网页同步区
聚合展示部署在 GitHub Pages 上的个人网页应用，点击即可在站内打开体验。重点推荐：

- **home** — 个人主页
- **暑假作业管理** — 多项目管理 / 日历排程 / 云同步
- **GESP 助手** — 考级刷题辅助
- **OIWB** — 信息学竞赛工具箱

其余卡片（约 9 个）由后台可视化维护。

### 2. 正经应用
规划中，敬请期待 🚧

### 3. 不正经应用

- **⏰ 时空穿梭机**（`time-machine.html`）
  - 穿越到未来：5 秒 / 1 分钟 / 5 分钟 / 1 天 / 自定义（真的要等那么久）
  - 穿越到过去：需开通「时空特权会员」（VIP 弹窗 + 微信扫码付款）
  - 炫彩旋转动画 + 进度条 + 时空不稳定提示 + 长穿越中途退出
- **🖥️ 桌面操作合集**
  - 浏览器模拟版（本窗口内，不影响真实桌面）
  - **桌面操控 EXE**（真实操控 Windows 桌面图标）：
    - 🌍 重力器 — 图标像被地球吸引一样掉落堆叠
    - 🛸 失重器 — 图标在桌面漂浮游动
    - 🥊 打架器 — 图标互相追逐碰撞
    - 🙈 消失器 — 图标躲到窗口后面
    - 👆 鼠标寻找器 — 箭头实时指向鼠标
  - 全部效果可一键复原（使用前请取消桌面「自动排列图标」）

## 🛠️ 管理后台（`admin.html`）

连接 GitHub 后即可可视化编辑网站内容，无需手改代码：

- **网页同步区** — 增 / 删 / 改同步仓库卡片
- **首页文案** — 编辑首页各区块展示文字
- **时光机文案** — 编辑时光机页面静态文案
- **桌面操作文案** — 编辑桌面操作合集说明
- **穿越结尾语** — 编辑穿越结算动态文案
- **文件管理** — 在线编辑仓库文件源码
- **发布 / 同步** — 一键整站发布到 GitHub Pages
- **连接 / 云端** — 配置 GitHub 用户名 / 仓库 / 分支 / PAT

> 💡 进入 `/admin.html`，填入 GitHub 用户名、仓库名、分支与具备 `repo` 权限的 PAT 即可使用。连接信息保存在浏览器本地，不会上传。

## 📁 目录结构

```
app-hub/
├── index.html          # 主站页面
├── time-machine.html   # 时空穿梭机
├── admin.html          # 管理后台
├── css/                # 样式表
├── js/                 # 脚本
│   ├── web-sync.js     # 网页同步区数据（后台可编辑）
│   ├── tm-done.js      # 时光机结算文案（后台可编辑）
│   └── ...
├── assets/             # 资源文件（微信二维码、桌面操控 EXE 等）
├── desktop_app/        # 桌面操控 EXE 构建源码（Python + pywebview）
├── site-settings.json  # 后台连接配置（由后台自动维护，勿手动修改）
└── deploy-manifest.txt
```

## 🚀 部署

项目托管于 GitHub Pages，源分支为 `main`。推送 `main` 后 GitHub Pages 会自动重建（CDN 缓存约 1~3 分钟生效）。

桌面操控 EXE 由 `desktop_app/` 下的 Python 源码打包（`pywin32` + `pywebview` + PyInstaller），独立于网页部署。
